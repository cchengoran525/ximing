# 夕明 · 余烬之城

复古城市背景的**类元气骑士**像素肉鸽射击游戏。纯 Web 技术（HTML5 Canvas + 原生 JS ES Modules），零运行时依赖。

## 三种启动方式

| 方式 | 操作 | 适合 |
|---|---|---|
| **单文件版（最简单）** | 双击打开 `standalone.html` | 日常玩，整个游戏是一个 html 文件 |
| **一键脚本** | 双击 `启动游戏.command` | 想从最新源码运行（需 python3） |
| **手动服务器** | `python3 serve.py` 后开 http://localhost:8130 | 开发调试 |

> 改了 `src/` 代码后想更新单文件版：`python3 tools/build.py`（需要 node/npx）。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 + 左键 | 瞄准 / 射击（可按住） |
| Space / Shift | 翻滚（无敌帧） |
| **F** | 释放主动技能（雷管 / 诱饵 / 绷带包） |
| E | 交互（购买/拾取/对话/合成/接契约/与齐青交流/进传送门） |
| Q | 切换武器（2 槽） |
| Esc | 暂停菜单 |
| M | 静音 |

## 玩法结构

- **四层结构**：每局先是三个随机顺序的区域，最后固定进入**议事厅**——最终 Boss「议长 · 执槌者」在红毯尽头等你。
- **三种区域各有空间性格**（房间不再是清一色方块，形状随机取 矩形 / L 形 / T 形 / 十字 / 八角 / 圆形 / 带缺口 等）：
  - **大建筑室内**：**许多小房间**（10-12 间，13×11 格上下）、形状各异、走廊窄如门厅；房间有**主题**——会议室（长桌+两侧椅子+玻璃隔断）、茶水间（饮水机+售货机+盆栽）、机房（成排机柜+空调+玻璃走廊）、档案室（成排档案柜，必出档案）、办公区（格子间+玻璃隔断）、门厅；部分房间是**地下一层 B1**（画面偏冷偏暗），与楼上由**楼梯**相连；楼层之间有**电梯**快速通勤（起点/中层/Boss 房三站）；
  - **室外街道**：**两条长街** + **垂直小巷**换街 + 街边店面（商店/宝箱/精英挂在街上）+ **可进出的小店**（货架、柜台、垃圾桶，可搜刮）；街上**路灯**（可打灭）、天桥与下水道（成对快捷通道，天桥跨过街段、井盖钻下水道）；
  - **城市外公路**：**开阔的大地图**（房间 30×20 ~ 48×32 格，全图 150×70 格以上），区域之间由**宽阔公路**连接；
- **可破坏环境**：玻璃隔断一发即碎（子弹穿过后继续飞）、木箱/办公桌/长桌/机柜/档案柜能被子弹打烂并**掉零件**（档案柜还有几率掉档案）、**饮水机被打爆会喷水**、垃圾桶可翻、**室外售货机砸开会掉东西但触发警报**（引来一波增援）、路边**报废车打爆会炸**并**连环引爆相邻车辆**、**路灯与霓虹招牌可以被射灭**（这一片随之暗下来）。被打烂的家具会开出新通路。
- **监控摄像头**：室内/议事厅的战斗房墙上装着摄像头，**视野扇形会缓慢摆动**（画面上能看到黄色光锥与扫描线）；被扫到就触发警报、召来增援；摄像头本身可以被打坏（掉零件）。
- **公路车流**：公路上有**汽车与卡车双向飞驰**；部分层还有一条**横穿整层的铁路**，**超长编组的火车（38-58 节车厢，约 2-3 个屏幕长）**呼啸而过。车辆出现前会有闪烁箭头预警与鸣笛，铁路沿线还会亮起**道口信号灯**；车辆会**同时撞伤敌我**——可以把敌人引到车道或铁轨上“借刀杀人”。火车预警更长（2 秒）、伤害更高（8 点）。
- **战斗与探索**：走进战斗区闸门落下、刷怪波次，清完开闸；小地图标注各房间类型与已探索状态。**敌人归属各自房间**（只在本房内活动、不会挤在闸门上，也不会把别的房间拖成"永远清不完"），**悬浮单位能越过大件家具但不会穿墙/闸门**；室内房间的**中央留出空场**，家具靠边摆放，打起来有走位空间。
- **场景陈设**：三个区域各有装饰与氛围——室内有会议长桌、储物柜、饮水机、白板与挂画；街道有电话亭（会闪灯）、邮筒、报摊、垃圾桶、水洼、交通锥与霓虹招牌；公路有轮胎堆、枯树、沙袋、路障与**会燃烧的篝火**；议事厅是大理石地面 + 红毯 + 拱柱 + 横幅。战斗会在地面留下弹壳、血迹与**焦痕**；室内暖光、街道雨雾蓝调、公路黄昏暖调是各自的画面基调。
- **精英词缀**：精英敌人随机携带一种词缀——狂暴、护甲（需先破盾）、分裂（死后裂成两只小怪）、灼燃（近身烧人）、潜行（远处隐形）。
- **武器合成**：起点区的**合成台**可把装备里的两把武器按配方拼成新武器（共 8 条配方，产物不入掉落池）。
- **悬赏契约**：起点区的**通缉板**每层提供 3 张契约，接一张接受本层限制换零件倍率。
- **主动技能**：敌人掉落 / 宝箱 / 售货机可获得雷管、诱饵、绷带包，按 F 释放。
- **结局**：击败议长后按条件触发不同尾声——默认「雨停了」；带着齐青走到最后是「同路人」；集齐 12 份档案是「档案里的城市」。
- **城市随进度演进**：每通关一次，广播里多一段新话、街上的旧旗帜与涂鸦变多、小屋窗外对面楼的灯一盏盏亮起来、还能在街头捡到新的档案。
- **基地小屋（局外）**：床（天赋）、工作台（解锁武器）、书架（档案）、**档案柜（敌人图鉴 / 武器图鉴 / 成就 / 统计）**、收音机（广播随时局变化）、门（出发）。
- **养成**：零件用于解锁 13 种武器、9 个天赋；12 项成就自动发奖。
- **齐青**：在**野外公路层第二次（或更晚）击败 Boss** 时触发解锁剧情（雨天站台）。解锁后：
  - 在小屋聊天；
  - **支线关「旧卫戍营房」**：跟他回一趟老部队（三处回忆点 + 旧队长），走完他的「拖了很久的一件事」，他的防暴伞会强化（伤害与射速 +25%）；
  - 被带进本自主战斗（跟随、走位、躲弹、伞击退、倒地可扶起）；
  - 局内 E 交互：互换武器、代管武器、每层一次的 2 选 1 加成共享。

## 剧情背景（仅氛围，不影响玩法）

革命已经"结束"五年了——执政厅每晚都这么广播。你（夕明）是旧城边缘一栋小屋的幸存者，靠翻检废弃城区的零件过活。城市的记忆散落在便签、涂鸦、旧报纸和一台滋滋作响的收音机里。

## 技术

- 512×288 低分辨率画布整数倍放大，`image-rendering: pixelated`
- 全部美术为代码内嵌像素表（角色 16×16、Boss 32×32、三套地形瓦片程序化生成）
- 音效与音乐由 WebAudio 实时合成（芯片音步进音序器），无任何音频文件
- 存档：localStorage（`ximing_save_v1`）
- 大地图：单层 110×77 左右瓦片，摄像机跟随 + 视口裁剪渲染；区域制闸门封锁
- 数据与逻辑分离（`src/data_*.js`），便于日后迁移 Godot

## 美术素材

游戏里的全部美术（角色、敌人、Boss、地形瓦片、道具、载具、武器图标）都已经导出成通用图片资源放在 **`assets/`**：PNG 单图 + 图集 + 坐标 JSON + 调色板 + 像素表源数据，另有 1x/2x/4x/8x 多种尺寸，可直接导入 Godot / Unity / Aseprite 等。详见 [assets/README.md](assets/README.md)。

改了美术后重新导出：`npm run export-assets`。
